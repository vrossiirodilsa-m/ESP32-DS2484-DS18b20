# ESP32-DS2484-DS18b20

ESP32 + DS2484 + DS18B20 Driver (Pure ESP-IDF) NO ARDUINO

Высокопроизводительный, модульный и неблокирующий драйвер для работы с мостом 1-Wire DS2484 и цифровыми датчиками температуры DS18B20 на базе микроконтроллера ESP32, написанный на чистом ESP-IDF (без использования Arduino-фреймворка и лишних абстракций).

## 🚀 Особенности проекта

* **Чистый ESP-IDF:** Никаких тяжелых Arduino-оберток (TwoWire, Print), только нативный driver/i2c и FreeRTOS.
* **Модульная архитектура:** Код разделен на независимые компоненты, которые легко переиспользовать в других проектах.
* **Асинхронный опрос (Non-blocking):** Запуск конвертации температуры по шине (Skip ROM) и ожидание готовности через короткие шаги с освобождением процессора, без слепых vTaskDelay на 750мс.
* **Полная поддержка 1-Wire Search:** Корректный алгоритм поиска ROM-адресов с бинарным деревом коллизий позволяет подключать любое количество датчиков DS18B20 в гирлянду.
* **Active Pull-up (APU):** Аппаратное ускорение фронтов линии 1-Wire через конфигурацию микросхемы DS2484 для стабильной работы на длинных линиях.

## 🔌 Подключение (Схема)

SDA GPIO 32  
SCL GPIO 33  
SLЗZ от ESP32 - 3.3в !!! Питание ds2484 и шины датчиков ds18b20 - 5в !!! Минус естественно везде общий.  
Адрес I2C микросхемы DS2484 по умолчанию: 0x18.

## 🛠️ Как это работает

* **Инициализация:** Настраивается шина I2C ESP32, сбрасывается чип DS2484 и включается активная подтяжка линии (Active Pull-up).
* **Широковещательный запуск (Broadcast):** Вместо опроса каждого датчика по очереди, мастер отправляет команду Skip ROM (0xCC), после чего команду Convert T (0x44) — все датчики на шине начинают измерение одновременно.
* **Ожидание:** Код опрашивает состояние линии в цикле с шагом 20мс (через vTaskDelay), не нагружая процессор впустую.
* **Сканирование и чтение:** Происходит стандартный поиск всех подключенных устройств через 1-Wire Search, после чего для каждого датчика запрашивается Scratchpad (0xBE), вычисляется реальная температура и выводится в логи с полным 64-битным ROM-адресом.
